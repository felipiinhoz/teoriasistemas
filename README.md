## 🚀 Como Visualizar a Apresentação Web

Abra o arquivo [`index.html`](index.html) no seu navegador ou publique no **GitHub Pages**:

### Publicando no GitHub Pages:
1. Suba este repositório para o seu GitHub:
   ```bash
   git init
   git add .
   git commit -m "Apresentação Teoria Sistêmica"
   git branch -M main
   git remote add origin https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
   git push -u origin main
   ```
2. No seu repositório no GitHub, vá em **Settings** > **Pages**.
3. Em **Source**, selecione a branch `main` e a pasta `/ (root)`.
4. Clique em **Save**. O link da sua apresentação estará no ar em poucos segundos!

## 💻 Recursos da Apresentação Web (`index.html`)

- `▶` / `Espaço`: Avança para o próximo slide
- `◀`: Volta para o slide anterior
- `F`: Ativa/desativa modo Tela Cheia (**Fullscreen**)
- `S`: Abre a gaveta com o **Roteiro de Fala do Apresentador**
- `O`: Abre a visão geral em mosaico (**Miniaturas dos 14 slides**)
- `Ctrl + P`: Imprime ou salva todos os slides em **PDF**
